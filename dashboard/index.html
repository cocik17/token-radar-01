How implied value is computed

One formula scores every row. No protocol name is special-cased and no row is hand-picked. The page recomputes each row from the snapshot figures and checks it against the number the board carries.

Category multiples

Median market-cap-to-TVL of live-token peers in the category, shrunk toward the global median when a category has few peers. Categories with no peers use the global multiple.

What this number is not

  • Implied value is a model estimate, not a price, a valuation, or a promise of a token.
  • “No token” means no token on record in the snapshot source — it is not a guarantee that a token will never exist.
  • Market caps in the live-token view are facts, not model output.
